\# Cybersecurity Portfolio — SOC e Network Security



Ho una laurea in Ingegneria Informatica e un master in Cybersecurity Specialist.

Questo repository raccoglie i laboratori pratici che ho costruito per consolidare

le competenze di un analista di sicurezza: operazioni di SOC (blue team),

rilevamento e risposta, e sicurezza delle reti.



\## Progetti



| Progetto | Cosa dimostra | Stack |

|---|---|---|

| \[wazuh-lab](https://github.com/Salvatore-Frisicaro/wazuh-lab) | Catena di detection end-to-end: creazione di un account locale (eventi Windows 4720/4722/4738/4726) rilevata dal ruleset Wazuh con mappatura MITRE T1098, con evidenze e troubleshooting documentato | Wazuh 4.14.9, Windows 10, VirtualBox |



\## Competenze dimostrate



\- \*\*SOC e detection:\*\* deploy di SIEM all-in-one, decodifica degli eventi, ruleset e mappatura MITRE ATT\&CK, triage degli alert

\- \*\*Endpoint:\*\* installazione e gestione dell'agent Wazuh su Windows, telemetria del registro di sicurezza

\- \*\*Operazioni:\*\* verifica di integrità degli artefatti, hardening delle credenziali, snapshot e ripristino dell'ambiente

\- \*\*Diagnostica:\*\* analisi dei log di sistema, stato dei servizi, verifica delle porte in ascolto, API REST

\## Approccio



Ogni progetto è documentato con obiettivo, architettura, passi riproducibili,

evidenze verificate e problemi incontrati con la relativa soluzione. L'obiettivo non

è mostrare che il software funziona, ma documentare il metodo con cui lo si verifica.
